Este projeto tem como objetivo o desenvolvimento de uma aplicação de monitoramento de sistema que coleta, processa e exibe informações de hardware em tempo real. Inspirado em ferramentas como o HWMonitor, o sistema permitirá acompanhar métricas como uso de CPU, memória, temperatura e outros indicadores relevantes de desempenho. A proposta é oferecer uma interface clara e eficiente para análise do estado do sistema e suporte à tomada de decisões relacionadas à performance e manutenção.
